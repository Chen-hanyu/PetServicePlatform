## 6. 最小自测说明

### 6.1 环境准备

1. 初始化数据库：

```sql
SOURCE backend/src/main/resources/sql/schema.sql;
SOURCE backend/src/main/resources/sql/seed.sql;
```

2. 启动后端：

```powershell
cd backend
.\mvnw.cmd spring-boot:run
```

3. 编译检查：

```powershell
cd backend
.\mvnw.cmd -q -DskipTests compile
```
