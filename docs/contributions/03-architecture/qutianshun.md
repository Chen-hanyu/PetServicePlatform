## 遇到的问题和解决
1. 问题：前端初始阶段只有目录占位，缺少可运行的工程骨架，无法高效并行开发。  
   解决：先完成统一工程初始化与架构落地（路由、状态管理、请求层、页面分区），再开展业务页面开发。

2. 问题：后端接口较多，字段命名和分页返回结构需要严格对齐，否则联调成本高。  
   解决：以 `docs/api.md` 和后端 DTO 为准建立前端 `types` 层，并统一 `services` 模块调用，避免页面散写接口。

3. 问题：用户端与管理端风格差异大，容易出现视觉不一致或可用性下降。  
   解决：采用统一 Design Token；用户端偏温暖亲和，后台偏清晰效率，保证品牌一致和交互可读性。

4. 问题：课程项目周期短，既要完成功能又要保证展示效果。  
   解决：先保证 MVP 主流程可跑通，再进行视觉迭代与体验优化，减少返工。
