## 遇到的问题和解决
1. 问题：项目页面较多，首页、社区、领养、服务、商城、个人中心之间容易出现风格不统一。
解决：先整理统一的设计说明，从配色、字体、圆角、阴影和组件规范入手，再逐页推进设计。

2. 问题：信息架构复杂，既要满足用户浏览体验，又要保证页面层级清晰。
解决：先输出信息架构文档，明确六大模块、页面入口和详情流程，再回到 Figma 做页面布局。

3. 问题：课程项目时间有限，设计既要完整又不能过度复杂。
解决：采用卡片式布局和轻量动效，优先完成核心页面与关键交互，控制实现成本。

这次 UI 设计让我更清楚地理解了从需求、信息架构到视觉规范再到页面落地的完整流程。相比只画单个页面，先整理设计说明和结构文档能明显减少返工，也更方便后续前端实现和团队协作。
