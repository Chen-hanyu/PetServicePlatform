## 遇到的问题和解决
1. 问题：功能模块较多，用户端与管理端页面容易出现布局和交互不一致。
解决：先统一页面骨架和组件规范，再分别细化各模块内容，保证跨页面一致性。

2. 问题：课程项目时间有限，既要覆盖完整功能，又要保证界面可实现。
解决：采用 MVP 思路，优先完成注册登录、宠物档案、预约、商城主链路页面设计。

3. 问题：文档和页面迭代不同步，容易导致开发与设计理解偏差。
解决：每次调整页面结构时同步更新 `docs/frontend.md`，把改动沉淀为可执行规则。

4. 问题：AI 生成界面速度快，但有时不完全贴合项目字段和交互约束。
解决：先用 AI 快速出结构，再按项目字段与接口约定做人工二次修正。
