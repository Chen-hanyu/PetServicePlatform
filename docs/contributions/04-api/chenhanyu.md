## 遇到的问题和解决
1. 问题：原有认证流程以验证码为主，与本次作业要求的注册、登录、登出接口不完全一致。
   解决：将用户端和管理端登录统一调整为手机号加密码模式，补充注册与登出接口，并同步更新安全配置、数据库字段和测试用例。

2. 问题：补充用户密码字段后，部分集成测试数据与测试表结构不一致，导致测试失败。
   解决：同步修改测试库表结构和测试 SQL 数据，恢复首页、搜索等模块所需的样例数据，重新跑通全部后端测试。

3. 问题：API 文档最初只覆盖了核心接口，不能完整反映当前项目的全部后端接口。
   解决：按实际控制器重新梳理用户端和管理端接口，补全 `docs/api.md` 与 `docs/api.yaml`，使文档与后端实现保持一致。

## 心得体会

这次接口设计和实现过程中，我对 RESTful 资源设计、统一响应结构、认证流程和接口文档之间的对应关系有了更清晰的理解。实际开发里不仅要把接口写出来，还要同步考虑状态码、权限、测试数据和文档一致性，否则前后端联调和后续维护都会受到影响。
