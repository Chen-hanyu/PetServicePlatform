# 宠物综合服务平台 - 管理员后台信息架构

## 项目定位
面向平台运营和审核人员的管理员后台，负责支撑用户管理、内容审核、领养审核、服务管理、商品管理、订单处理和运营配置等后台业务。

## 核心流程

### 1. 帖子审核流程
管理员后台  
├── 进入内容管理  
├── 查看待审核帖子列表  
├── 打开帖子详情  
├── 选择通过/驳回  
└── 写入审核结果与备注  

### 2. 领养申请审核流程
管理员后台  
├── 进入领养管理  
├── 查看申请列表  
├── 打开申请详情  
├── 对照申请资料和宠物状态审核  
└── 更新申请状态  

### 3. 商品管理流程
管理员后台  
├── 进入商城管理  
├── 查看商品列表  
├── 新增或编辑商品  
├── 维护价格与库存  
└── 执行上架/下架  

### 4. 预约单处理流程
管理员后台  
├── 进入服务管理  
├── 查看预约单列表  
├── 按状态筛选  
├── 处理预约状态  
└── 记录处理结果  

---

## 页面结构特点
- 仪表盘承担数据总览和待处理任务入口作用
- 各业务模块以“筛选栏 + 表格 + 详情抽屉/弹窗”为核心结构
- 管理操作分为查看、编辑、审核、状态处理、批量操作五类
- 后台信息架构强调高频操作路径短、审核链路清晰、状态反馈明确
