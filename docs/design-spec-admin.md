# 管理员后台设计说明

## 1. 文档概述
本设计说明面向宠物综合服务平台管理员后台，用于统一后台管理界面的视觉风格、信息密度、交互模式与实现方向。文档适用于后台页面设计、前端实现和课程项目汇报说明。

管理员后台服务于平台运营与审核场景，因此设计策略遵循以下原则：
- 信息密度高于用户前台，但不能牺牲可读性
- 保持与平台主品牌一致的视觉识别
- 优先保证表格、筛选、审核、状态管理的效率
- 支持基于 Vue 构建管理后台页面

---

## 2. 设计目标
- 构建一套清晰、高效、易操作的后台管理界面
- 支撑用户管理、内容审核、领养审核、服务管理、商品管理、订单处理等核心后台流程
- 保持与用户前台同一品牌体系，但在排版和组件层面更偏工具型与数据型
- 通过统一规范降低页面维护成本和多人协作成本

---

## 3. 视觉风格
### 3.1 风格定位
管理员后台整体视觉风格为：
- **专业清晰**
- **数据导向**
- **轻量统一**

### 3.2 风格关键词
- 高效
- 稳定
- 清晰
- 克制
- 可操作
- 数据化
- 审核导向
- 管理型

### 3.3 视觉表现方向
- 采用浅色后台界面，保证长时间使用的阅读舒适度
- 保留品牌主色作为状态和重点操作色，不做大面积装饰
- 布局以左侧导航 + 顶部工具栏 + 内容工作区为主
- 表格、筛选栏、状态标签、抽屉和弹窗作为核心交互组件
- 动效尽量克制，重点用于状态反馈和页面切换

---

## 4. 配色方案
### 4.1 主配色
- **品牌主色：#7ECFBC**  
  用于激活菜单、主按钮、选中状态、统计高亮
- **后台深色：#2F3A38**  
  用于侧边导航、标题、重点文字
- **辅助背景：#F6F8F8**  
  用于后台整体页面背景
- **强调色：#FFD66B**  
  用于待处理提醒、重点提示和运营位标识

### 4.2 中性色
- **主文字色：#25312F**
- **次文字色：#5F6B68**
- **弱文字色：#8B9794**
- **边框色：#DDE6E3**
- **卡片背景：#FFFFFF**
- **表格斑马底色：#FAFCFB**

### 4.3 功能色
- **成功：#5BB98C**
- **警告：#F3B63F**
- **错误：#E97A7A**
- **信息：#73A7E8**
- **审核中：#8F7AEA**

### 4.4 配色使用原则
- 品牌主色只用于关键操作、导航激活与局部高亮
- 审核状态、上下架状态、订单状态必须依赖功能色区分
- 大面积区域优先使用白色或浅灰绿背景，避免视觉疲劳
- 后台图表和统计卡片在保持品牌统一的同时，优先保障区分度和可读性

## 5. 字体规范
### 5.1 字体方案
- **标题：PingFang SC Semibold / Microsoft YaHei Bold**
- **正文：PingFang SC / Microsoft YaHei / sans-serif**
- **数据与编号：Fira Sans / Consolas / monospace（可选）**

### 5.2 字体使用建议
- 后台不强调装饰性字体，统一使用清晰稳定的系统中文字体
- 表格数字、订单号、状态编码可适度使用等宽字体增强对齐感
- 标题字重高于前台，用于强化信息层级和模块分区

### 5.3 字号层级建议
- 一级标题：24px / 600
- 二级标题：18px / 600
- 三级标题：16px / 600
- 正文：14px / 400
- 辅助文字：12px / 400
- 表格文字：13px / 400
- 按钮文字：14px / 500

### 5.4 行高建议
- 标题行高：1.3 - 1.4
- 正文行高：1.5 - 1.7
- 表格内容行高：1.4 - 1.6

---

## 6. 图标与图表风格
### 6.1 图标风格说明
- 图标以简洁的线性图标为主
- 后台常用图标包括用户、审核、订单、商品、服务、消息、统计、筛选、导出
- 图标风格应统一，不使用装饰性过强或拟物化图标

### 6.2 图表使用规范
- 仪表盘可使用柱状图、折线图、饼图、环形图展示核心运营数据
- 图表颜色应优先使用品牌色 + 功能色组合
- 图表说明与图例必须清晰，避免仅靠颜色传达状态

---

## 7. 布局与间距规范
### 7.1 页面布局
- 后台采用经典管理系统布局：左侧导航、顶部栏、主体工作区
- 主体工作区内使用统计卡片、筛选栏、数据表格、详情抽屉和弹窗组合
- 页面内容优先横向利用空间，提高管理效率

### 7.2 间距建议
- 页面大区块间距：24px
- 模块内部间距：16px
- 表格操作区间距：12px
- 表单项最小间距：8px

### 7.3 圆角建议
- 大卡片圆角：16px
- 普通卡片圆角：12px
- 输入框/按钮圆角：10px
- 标签圆角：999px

### 7.4 阴影与边框规范
- 统计卡片使用轻阴影强调层级
- 表格和筛选区域优先采用边框分隔，避免过多阴影
- 推荐阴影：`0 6px 16px rgba(34, 60, 52, 0.06)`
- 边框颜色统一使用浅灰绿，保证后台整体干净统一

---

## 8. 组件设计建议
### 8.1 导航
- 左侧导航展示核心后台模块
- 支持一级导航和必要的二级导航展开
- 当前模块必须有明显高亮与路径提示

### 8.2 统计卡片
- 用于展示用户数、订单数、待审核量、预约量等核心指标
- 卡片包含标题、数值、趋势或说明
- 重要异常指标可使用警告色提示

### 8.3 筛选栏
- 由搜索框、下拉筛选、状态筛选、时间筛选、重置按钮组成
- 固定放置在数据列表上方，减少操作路径

### 8.4 表格
- 后台核心展示组件，必须支持分页、排序、批量选择和状态展示
- 行内操作建议控制在 2 到 4 个以内，复杂操作放到更多菜单

### 8.5 抽屉与弹窗
- 抽屉用于详情查看和轻量编辑
- 弹窗用于删除确认、审核确认、状态变更等强操作场景

### 8.6 状态标签
- 用于审核状态、订单状态、上架状态、预约状态等
- 必须结合功能色统一命名和视觉表达

## 10. 交互说明
### 10.1 基础交互
- 点击左侧导航进入对应管理模块
- 点击统计卡片进入详情或关联列表
- 点击表格行查看详情或执行操作
- 点击审核按钮弹出确认弹窗

### 10.2 反馈交互
- 提交、审核、删除、上下架等操作必须显示明确反馈
- 长耗时操作显示加载状态
- 批量操作完成后需提示成功数量或失败原因

### 10.3 列表交互
- 支持分页、排序、关键词搜索、多条件筛选
- 支持批量选择和批量处理
- 表格空状态与异常状态需给出提示

### 10.4 表单交互
- 必填项清晰标识
- 校验错误在字段附近显示
- 保存、提交、取消按钮分层明确

### 10.5 动效建议
- 页面切换使用轻过渡
- 弹窗、抽屉、下拉筛选有基础过渡动画
- 不使用复杂炫技动画，保证后台操作稳定感

---

## 11. 动效规范
### 11.1 动效原则
- 克制
- 清晰
- 有反馈
- 不干扰数据阅读

### 11.2 推荐动效场景
- 菜单展开/收起
- 抽屉打开/关闭
- 筛选条件切换
- 表格加载状态
- 提交和审核结果提示

### 11.3 动效表现建议
- 使用透明度、位移和高度变化为主
- 动效时长控制在 150ms - 250ms
- 支持 `prefers-reduced-motion`

---

## 12. 实现建议
### 12.1 前端实现方向
- 使用 Vue 3 + Vite 构建管理后台
- 采用路由 + 权限控制的方式管理页面访问
- 通过通用表格、筛选栏、详情抽屉组件提升复用性

### 12.2 推荐拆分思路
- 公共组件：侧边导航、顶部栏、统计卡片、表格、分页、筛选栏、状态标签、审核弹窗
- 页面组件：用户管理、内容管理、领养管理、服务管理、商城管理
- 公共样式：颜色变量、状态色、圆角、阴影、表格样式、表单样式

### 12.3 样式建议
- 通过 Design Token 统一管理前后台共享品牌色
- 后台局部可引入更强的中性色体系，强化工具型界面特征
- 保持表格、按钮、状态标签和弹窗样式统一，降低认知成本
